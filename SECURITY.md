# Security

This repository is designed to run without network access or external
credentials. The reference assurance provider is deterministic and exists to
exercise the neutral assurance protocol in the synthetic runtime.

Do not add credentials, customer data, private URLs, or production connection
settings to this repository. Security-sensitive integrations should be
implemented outside the public core and injected through neutral protocols.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Until a dedicated
security contact is established, report it privately to the project
maintainers through the hosting service's private security mechanism, if one
is available, and include the affected version, reproduction steps, impact,
and a proposed mitigation. Do not include credentials or sensitive data in a
report.

This document describes the repository's reporting process; it is not a
guarantee of production security or suitability for a particular deployment.
