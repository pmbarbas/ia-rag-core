# Security

This staging repository is designed to run without network access or external
credentials. The reference assurance provider is deterministic and exists only
to exercise the neutral assurance protocol in tests.

Do not add credentials, customer data, private URLs, or production connection
settings to this repository. Security-sensitive integrations should be
implemented outside the public core and injected through neutral protocols.

This repository is not yet a published security-support channel. Licensing
and release decisions remain pending.
